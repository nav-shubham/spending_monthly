========================================================================
💵 UPI SPENDING ANALYZER PRO - DETAILED APPLICATION SPECIFICATION & MANUAL
========================================================================

1. OVERVIEW
------------------------------------------------------------------------
UPI Spending Analyzer Pro is a local-first, personal finance intelligence
application built in Python and Streamlit. The application processes monthly
UPI statements from multiple digital wallet/payment providers, cleans and
normalizes transaction descriptions, aggregates duplicate UPI IDs under canonical
merchants, tracks category budgets, identifies recurring subscription payments,
provides advanced visual analytics and forecasting, and exports reports.

All imported statements and rules configurations are persisted in a local,
relational SQLite database with duplicate detection, enabling high-performance
reads and write operations on datasets of 100,000+ records.


2. TECHNICAL ARCHITECTURE & MODULAR DESIGN
------------------------------------------------------------------------
The codebase adopts a strictly decoupled, modular architecture adhering to SOLID
design principles:

a) Core UI Layer (app.py, src/styles.py)
   - Built on Streamlit with a premium dark-themed styling system.
   - Provides responsive layout configurations using width='stretch' alignments.
   - Houses the interactive Plotly visualizations (cashflow trends, category donut charts,
     weekly/seasonal spending profiles, hierarchical sunburst drilldowns, and forecast lines).

b) Data Persistence Layer (src/db.py)
   - Utilizes standard SQLite3 to handle persistent storage.
   - Normalized relational schema mapping categories, vendors, mapping rules,
     budgets, transactions, and import history logs.
   - Employs compound indexes on queries to optimize retrieval of large datasets.
   - Dynamically adds the DefaultVendor column by applying narration-cleaning logic.

c) Statement Parser Layer (src/parser.py)
   - Implements format-agnostic parsing. Automatically detects and standardizes
     Paytm (.xlsx), PhonePe (.csv), Google Pay, and generic CSV/Excel layouts.
   - Normalizes distinct data columns into unified database-friendly parameters.
   - Calculates SHA-256 hashes of statement files to track file sync histories
     and avoid duplicate processing.
   - Cleans transaction prefixes (e.g. "Paid to", "Payment for", "Transferred to self").

d) Merchant Resolution Rules Engine (src/mapping.py)
   - Implements a prioritized merchant resolver that applies exact VPA matches,
     regex patterns, and substring matches in priority order.
   - Keeps rules in-memory for high-performance vectorized lookups.
   - Logs rule execution counts and timestamps.
   - Provides UI alerts when a transaction triggers multiple conflict resolution paths.

e) AI Suggestions Engine (src/ai_suggest.py)
   - Identifies unknown merchants. Generates suggested names, confidence scores,
     and explanations.
   - Integrates with the Gemini API (using HTTP POST requests to bypass package imports).
   - Falls back to local regex-based NLP heuristic cleanup rules if no key is configured.
   - Supports 1-click approvals that instantly write exact match rules to the database.

f) Financial Analytics Engine (src/analytics.py)
   - Computes core KPIs: Inflows, Outflows, Net Savings, and Savings Rate.
   - Calculates daily spending volatility (Standard Deviation) and monthly CAGR.
   - Fit linear regression models using numpy polyfit to forecast future spending.
   - Groups seasonal spending profiles across historical calendar months.

g) Subscription & Subscription Due Detector (src/subscription.py)
   - Groups transactions by merchant and amount to measure periodic intervals.
   - Classifies monthly (25-35 day spacing) and annual (350-375 day spacing) recurring events.
   - Estimates yearly subscription costs.
   - Flags missed subscription dues (if current elapsed days exceed 1.5x expected interval).

h) Exporters & Reporting Module (src/report.py)
   - Generates Excel workbooks with multiple worksheets using openpyxl.
   - Generates raw CSV transaction dumps.
   - Generates printable HTML statement summary sheets styled with Google Fonts.


3. PERSISTENT DATABASE SCHEMA
------------------------------------------------------------------------
The database schema consists of the following 6 tables:

- transactions: Contains transaction date, time, raw descriptions, amount, clean tags,
  self-transfer/mandate boolean flags, source file names, category FK, and vendor FK.
  Unique Constraint: (parsed_date, time_str, transaction_details, upi_id_or_acc, amount_numeric)
  avoids transaction-level duplicates.

- vendors: Stores unique merchant names and holds a default category FK.

- categories: Stores default and custom category names (e.g., Food, Groceries, Travel).
  is_system column flags default categories to prevent user deletion.

- mapping_rules: Stores match patterns, target merchant names, rule type (exact, pattern, regex),
  priorities, enabled flags, usage counts, and last used timestamps.

- import_history: Tracks processed file names, file hashes, import timestamps, and transaction counts.

- budgets: Maps category IDs to user-defined monthly limit limits.


4. USER MANUAL & FEATURE WALKTHROUGH
------------------------------------------------------------------------
- Syncing Data: Set the path to your statements directory in the sidebar and click
  "Sync Statements". The app parses the new statements, cleans descriptions, resolves merchants,
  and populates the database. Skipped duplicate transactions are flagged in the sync summary.

- Setting Budgets: Navigate to "Budgets & Subscriptions". Select a category, enter your monthly
  rupee limit, and click "Save". The app displays progress bars tracking current month spending
  against these thresholds, with warning alerts if limits are exceeded.

- Managing Rules: Review rules in "Vendor Rule Engine". Toggle enabling, adjust priority weights,
  or delete obsolete paths. View conflict warnings if multiple rules trigger.

- Resolving Merchants: Go to "AI Suggestion Assistant" to view unresolved merchants. Inspect suggestions
  with confidence scores and reasoning, then click "Approve" to save the rule.

- Downloading Reports: Generate Excel budgets spreadsheets, raw CSV data dumps, or download
  a printable HTML Monthly Executive Summary.


5. TESTING & QUALITY ASSURANCE
------------------------------------------------------------------------
The application is validated by 15 automated unit tests:
- tests/test_parser.py: Validates cleaning, prefix stripping, PhonePe/generic format detection.
- tests/test_mapping.py: Tests exact, pattern, regex resolution, priority sorting, conflict flags.
- tests/test_analytics.py: Asserts math for KPIs, monthly trends, volatility, and linear forecasting.
- tests/test_subscription.py: Verifies monthly/annual subscription detection and keyword matching.

To run the test suite:
  uv run pytest
